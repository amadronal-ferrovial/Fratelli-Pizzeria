# Instrucciones para agentes

Sigue [CONTRIBUTING.md](CONTRIBUTING.md): trabaja en una rama `issue/<nombre-del-issue>` creada desde `origin/dev`, no hagas push a `main` ni a `dev`, y abre un PR contra `dev` cuando `npm test` pase.

El desarrollo sigue Spec Kit (`/speckit-*`); las specs viven en `specs/`.
